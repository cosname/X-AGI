# X-AGI 2026 Brand Masters

This directory contains the curated vector masters for the 2026 X-AGI identity.
These files are source material and are not copied into the published site.

Runtime-ready assets used by the website live under `public/2026/brand/`.
Create new exports from these masters only when the live site needs a specific format or size, then place that selected export in the 2026 public directory.

- `mark.svg`: primary mark on light surfaces.
- `mark-on-dark.svg`: primary mark on dark surfaces.
- `wordmark.svg`: full wordmark on light surfaces.
- `wordmark-on-dark.svg`: full wordmark on dark surfaces.
