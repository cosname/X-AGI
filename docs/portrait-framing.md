# 嘉宾头像标准

本标准由用户于 2026-09-29 确认，适用于 2026 官网嘉宾和主席头像。

## 构图

- “上三分之一”指双眼中点接近圆框自上而下的 1/3 高度，通常落在 33% 至 40% 区间。
- 人脸水平居中，完整保留头顶、头发、耳朵和下巴，并留出头顶余量。
- 保留自然的颈部和肩部比例，避免整个圆框只有脸，也避免人物过小。
- 完整头部和自然比例优先于精确贴线。
  原图已经很紧时，允许眼位略低，并在逐张复查中记录来源限制。
- 不生成或补画五官、头发和身体，不为纠正构图旋转人物本身。
- 机器人、星空等非人像头像保留投稿者原图，不套用人脸构图规则。

## 实现与更新

原始照片存放于 `assets/source-archive/2026/people/`，保留来源映射。
运行时 WebP 保留完整原图宽高比，不预先自动裁成紧贴脸部的正方形，并移除 EXIF 等私有元数据。
逐人取景参数统一维护在 `src/data/portrait-framing.ts`，使用原图坐标，不改变既有头像圆框尺寸和嘉宾排布。
首页和日程共用 `portraitStyle`，海报沿用相同纵向取景并适配 4:5 外框。
仅纯白背景原图可在圆框内利用白色留边，不能出现截断肩部的明显水平边缘。
新增或替换照片后必须重新检查对应取景参数，不能直接沿用旧照片的坐标。
更新运行时头像或取景参数后，运行 `npm run posters:render` 同步海报与生成清单。

## 复查要求

逐张对照原图与实际圆形渲染，检查眼位、头顶、耳朵、下巴、水平位置、肩部和背景接缝。
自动人脸测量只能辅助定位，不能代替人工查看圆形裁切效果。
核对首页和日程在桌面及手机上的一致性，并确认所有头像加载成功、占位符不受影响。
同步查看海报，避免运行时图片变化导致其他位置重新裁掉头顶。
