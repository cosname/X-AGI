# 首页演讲嘉宾阵容

首页 lower page 的演讲嘉宾板块直接展示人物头像、姓名、简写职位和单位。
保留“完整日程”入口，人物链接直接指向日程页对应的简介展开项。
该板块不再展示专题宣传海报、报告题目、日期筛选或海报弹窗。
其后独立的论文展示、历届影像、组织信息，以及首页首屏均保持原有职责。

## 人物与内容来源

`src/data/home-speakers.ts` 从正式日程的 Speaker 顺序派生阵容，按人物 ID 去重，只纳入已有本地头像的演讲嘉宾。
当前为 41 位，缺少头像的其余讲者仍在完整日程中展示。
头像和单位复用既有公开人物资料及会务明确提供的补充资料，不生成讲者人像。
2026-09-17 根据会务提供的照片和简介补齐孙茂松，简介原文保存在 confirmed 人物资料中，首页按正式日程序列展示。
职位从同一份已公开简介中简写，英文职位翻译为中文，并保留对应原文片段以便核验。
简介没有明确职位时省略职位，不推测职级或学生身份。
当来源简介改变而原文片段不再匹配时，构建会要求重新核对职位。

## 展示与交互

`GoalSpeakers.astro` 使用同步横向滚动的多行列表，在 64rem 及以上视口展示三行，较窄视口展示两行。
人物按原有日程顺序逐列排列，第二行向右错开半列，48rem 及以下视口缩小至四分之一列，形成交错的头像阵容并让手机初始视图能看到两行头像。
所有行共用原生滚动容器和上一组、下一组按钮，触屏可横向滑动，键盘可逐项访问简介链接。
增强脚本在可滚动时支持上一组、下一组以及列表焦点下的左右方向键、Home、End。
系统要求减少动态效果时关闭平滑滚动。
人物照片延迟加载，并使用既有 640×640 头像文件。
每位嘉宾的头像、姓名及资料行共用同一条居中轴线，姓名独占一行，职务与单位在下一行并排展示。
行间距为 1.75rem，桌面人物列宽为 20rem、列间距为 1.5rem、头像为 9rem。
48rem 及以下视口的人物列宽不超过 20rem 或视口减去两侧共 2rem 的留白、列间距为 1rem、头像为 7.5rem。
资料行字号在 0.8rem 到 0.85rem 之间适配，确保现有职务和单位在 320px 及以上视口均完整显示在同一行。
原生滚动范围包含错位人物的实际边界，不额外添加尾部留白，确保到达末尾时最后一位嘉宾完整可见。
底部原生滚动条的左边缘与标题和首个人物列对齐。
旧的 `#goal-session-posters` 锚点保留在同一板块。

原有 14 张专题海报及其源素材、生成数据、渲染脚本继续保留。
海报不再作为首页阵容展示的运行时依赖。
发布状态以实际提交、CI、OSS 同步和公网校验记录为准。
