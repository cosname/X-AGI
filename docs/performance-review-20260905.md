## 审查发现与处理

### 1. 隐藏场景仍持续工作

手机竖屏隐藏桌面像素树，但原运行时仍会扫描树像素并逐帧修改样式。
现在把响应式可见状态加入动画调度条件，隐藏时不收集分支布局、不启动翻转循环。
恢复横屏时重新测量并恢复原动效。
页面隐藏、离开或从页面缓存恢复时，动画状态也会对应停止或恢复。

移动连接场景每次位移从两次 CSS 自定义属性写入改为一次直接 transform 写入。
节点、连线、漂移幅度和更新节奏保留。
内页装饰场景离开视口后不再跟随滚动重复测量。
页头滚动状态只有发生变化时才写入 DOM。

### 2. 内页携带首页代码和样式

把树的浏览器运行时移到 `src/scripts/hero-pixel-field-runtime.ts`，让内页只导入实际使用的数学辅助函数。
把首页构图和响应式规则移到 `src/styles/home-2026.css`，只由首页布局加载。
共享导航和玻璃材质变量仍留在全站样式中。
桌面导航使用自己的液态胶囊时，共享移动菜单胶囊不再重复渲染。
保留原来的静态样式回退，避免叠出第二层选中阴影。

### 3. 图片传输存在可去除的开销

新增 `scripts/optimize-runtime-pngs.mjs`，默认只报告潜在节省，传入 `--write` 才更新运行时 PNG。
压缩明确禁用调色板量化，并校验解码后的 RGBA 数据完全一致。
只接受更小且像素一致的结果。
2026 源文件归档及冻结的 2025 文件均保持不变，源归档校验通过。
现有 Astro 图片尺寸、WebP 输出、响应式图片及画廊懒加载继续保留。

## 用户体验修复

### 首页按钮拖拽

触摸横向移动超过起始阈值后，使用菜单同一套液态形变算法，在两个按钮之间连续预览。
松手在有效按钮区域内，进入选中的原始链接一次。
普通轻触、键盘聚焦和 Enter 保持原链接行为。
纵向手势仍交给浏览器滚动；拖出、系统取消或失去捕获时恢复报名默认态。
形变材质与外层投影分离，拖拽途中保留玻璃的厚度感。

### 树根遮挡

从所有山丘的同一组阶梯轮廓计算上沿，把树裁切在上沿以上。
山丘移动时裁切同步更新，响应式高度也使用同一 CSS 变量。
无需加深山丘颜色或覆盖纸张纹理。
1440 × 1000、1280 × 720、844 × 390 三种尺寸下，右侧山丘内部残留的树像素分别从 2,977、2,414、972 个变成 0。
该检查避开轮廓边缘 3 像素的抗锯齿区。

### 轻触传播连接

轻触手机竖屏首页的非交互区域，最近的连通节点亮起，光点沿已有连接依次传递并消退。
传播遵循图上的距离，不跨越未连接的节点群，也不新增穿过正文的连线。
滚动、长按和取消手势不会触发传播。
连续轻触只保留最新的一次反馈，避免累积动画。
“减少动态效果”模式只短暂点亮一个节点，不运行传播或持续漂移动画。

## 测量方法与证据

基线与修改后分别以生产构建在本地 4330、4331 端口提供，排除 Astro 开发服务器和 HMR 的影响。
视口为 1440 × 1000 或 390 × 844，DPR 为 1。
等待页面和字体加载后，使用 CDP Performance 指标计算 2 秒空闲窗口的耗时差值。
主结果使用基线与修改版本交替加载、各 3 次测量的中位数。
视觉比较开启减少动态效果，以免把动画相位差当成布局变化。
gzip 数字由构建产物离线计算，本地 HTTP 服务本身未开启压缩。
本次没有调整生产 CDN、缓存策略或部署配置。
