## 论文预览更新

`src/data/paper-preview-sources.json` 记录每篇论文的公开 PDF URL、原文件 SHA-256 或本次未取得来源的状态。
生成器核对 PDF 文件签名、摘要与首页题名，使用 Poppler 将完整首页渲染为 1400px PNG，再用 Sharp 输出 640px WebP。
PNG 保留在非公开 source archive，网页仅按需加载压缩后的 WebP；图片自带尺寸，采用 lazy loading 和 async decoding。
CVF 的 VKG-QA 网页题名与 PDF 题名存在措辞差异，已在来源记录中保存实际 PDF 题名用于校验，目录沿用官方网页题名。

```sh
npm run papers:render -- output/paper-previews-20260916
npm run assets:verify
```

渲染前，将来源记录对应的公开 PDF 放入指定缓存目录，命名为 `<paper-id>.pdf`。
缓存不进入版本库。
`src/data/paper-previews.generated.json` 及全局 archive manifest/checksums 由生成器更新，不应手工修改。
构建验证会拒绝来源状态遗漏、题名或摘要过期、未审阅域名、图片校验失败及缺失的预览链接。
Poster 内页增加静态图片链接后约 54 KB，其 HTML 上限单独调整为 60 KB，其他内页预算不变。

## 数据边界与更新

公开模块仅含稳定 ID、论文标题、报名人、学校或单位、会议或期刊、公开论文链接六个字段。
邮箱、电话、订单、审核明细、简历、录用证明及报名平台附件链接不进入网站或版本库。
原始 XLS 保留在用户提供的位置，不作修改，也不复制进仓库。
输入文件 SHA-256 为 `38b4f605976e537450dfa56b9776c4a29144e41f9dea797a13448500fe2d88ea`。

执行导入前，应在校订 JSON 中为新记录填写完整标题、公开链接、会议或期刊和证据。
记录键由报名姓名、原填标题与原填链接计算，未知记录会停止导入，避免无依据补齐或静默替换。
同一论文只按校订后的稳定 ID 去重，同名不同论文保持独立。
导入器使用隔离的 LibreOffice profile 读取 XLS，转换产生的临时 CSV 在 `finally` 中删除。

```sh
npm run posters:sync-research -- --workbook '/absolute/path/to/attendee-list.xls'
npm test
```

`src/data/poster-research.generated.ts` 由导入器生成，不应手工编辑。
构建检查会验证公开字段、题名、链接、稳定 ID 和校订记录的一致性。
页面保留完整静态目录，JavaScript 只负责搜索、会议筛选和结果计数。
目录视觉沿用网站现有的 `--glass-shell-*`、`--glass-micro-*` 与 `--glass-lens-*` 材质变量，以及深蓝墨色、紫色和纸感底色。
搜索与筛选使用玻璃胶囊控件，论文列表保持清楚的文字层级，聚焦时呈现轻量玻璃高光。
